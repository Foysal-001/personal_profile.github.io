4-bit Barrel Shifter

Developed as part of CSE260 Digital Logic Design coursework. This project implements a 4-bit barrel shifter using combinational logic, allowing rapid shift operations (logical left, logical right, and rotate) on a 4-bit binary input. Efficient hardware utilization minimizes gate count while achieving high-speed performance.
